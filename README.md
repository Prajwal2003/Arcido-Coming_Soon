# Arcido.in

A modern Next.js website for Arcido, featuring a custom design, interactive particles background, and social media integration.

## Getting Started

1. **Install dependencies:**
   ```sh
   npm install
   ```
2. **Run locally:**
   ```sh
   npm run dev
   ```
   Visit [http://localhost:3000](http://localhost:3000)

## Build for Production

```sh
npm run build
npm start
```

## Deploy
- **Recommended:** Deploy to [Vercel](https://vercel.com/) for best Next.js support.
- Or, use any Node.js host. Serve with `npm start` after building.

## Features
- Custom font and branding
- Interactive particles.js background
- Responsive, modern layout
- Social media links
